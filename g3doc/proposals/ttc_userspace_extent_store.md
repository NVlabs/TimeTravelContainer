# Historical TTC userspace extent-store proposal

This proposal is superseded. TTC no longer uses its proposed byte-keyed extent
layout. Current filesystem objects, bounded immutable metadata trees,
reference accounting, and reclamation are specified by the
[snapshot-graph storage refactor](ttc_snapshot_graph_refactor.md).

For current user-visible storage behavior, see the
[TimeTravelContainer user guide](../user_guide/timetravelcontainer.md).
